- [Hello World with Jev](./jev-hello-world/) — TypeScript console example that uses Jev and OpenRouter to make structured decisions about a rainy afternoon.
- [Kubernetes: Your First Project](./kubernetes-first-project-3811033/) — Course overview for containerizing a static website and deploying it to Kubernetes.
- [Pizza app](./pizza-app-blitzjs/) — Blitz.js app for managing pizzas and toppings.
- [Sample NestJS app](./sample-nest-app/) — A sample API with a controller and service for cats.
- [Toy train](./toy-train/) — Java project that models trains and track segments and renders the world in a console.
